\section{Abstract}
The objective of the project was to develop a system consisting of the following subsystems: The Universal Robot, involving the kinematics of the robot, running on the computer/main program, which is also in charge of controlling all parts of the system. The second is a gripper where a camera is attached utilizing computer vision to find the objects on an assigned grid. The third system is a user interface making it easy to build a predefined structure. The goal was to design and create our own gripper, that was able communicate with the robot using TCP, and consequently open/close and relocate the object appropriately based on sent commands. various of different kinds of test was conducted to conclude if the assumptions above was meet, which they were and the rapport will delve deeper down in the each specific part of the system.
