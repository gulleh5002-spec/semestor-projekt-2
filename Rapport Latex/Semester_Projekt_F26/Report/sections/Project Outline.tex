\section{Project Outline}
For the second semester project in Robotics the “task” is to design a system that manipulates a robot arm. With the goal of developing a custom gripper for the arm to manipulate objects. The system has the objective of interfacing with the arm via sensor input. To solve the task of identifying and picking up different colored objects and then placing them in predefined positions to make structure. 


To manipulate the objects the task required the usage of a UR robot, and a self designed gripper. Including an interface programmed with C++, where a grid is used to define the objects end positions and the overall structure via user input and a program is used to check if it's valid. The objects’ starting position is in a tray where a sensor is used to find the orientation of said object. 


The project is divided into four focus areas:

\begin{itemize}
\item Mechanical Design: 
Creating different 3D printed gripper designs and choosing the best one based on the testing of each one for the specific task. \\

\item Electronics and Sensors:
Designing, building and testing different sensor setups, and then choosing the best suited setup for the goal. \\

\item Software integration: 
Developing C++ programs for each area: One for controlling the arm, another for the gripper, and a third program for the sensor management. \\

\item User Interface: 
Creating a Simple grid GUI that allows the user to pick the shape or structure they want the robot to create. 
\end{itemize}
